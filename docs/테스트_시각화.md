## 4. 개별 실행 케이스

**읽는 법:** 각 표의 ID는 이 문서에서 부여한 식별자입니다. 매개변수 이름은 이해하기 쉽게 번역했으며, 값은 원본을 기준으로 표시했습니다. 긴 PR 응답 매개변수는 차이가 드러나는 조건명으로 요약했습니다. 원문 전체는 각 함수의 소스 링크에서 확인할 수 있습니다.

보이지 않는 문자는 <code>U+200B</code> 등의 코드 포인트로, 제어문자는 <code>&#92;x1b</code> 등의 표기로 나타냅니다. <code>&#92;n</code>은 줄바꿈, <code>&#92;t</code>는 탭, <code>""</code>는 빈 문자열입니다. <code>&amp;#8203;</code>는 원본의 문자 참조 표기입니다.

## 5. 다시 확인하는 방법

프로젝트 루트에서 README에 안내된 운영체제별 가상환경을 사용합니다.

| 목적 | 명령 |
| --- | --- |
| 전체 결과 확인 | <code>uv run --locked pytest -q</code> |
| 수집된 케이스 목록 확인 | <code>uv run --locked pytest --collect-only -q</code> |
| AI 서비스만 실행 | <code>uv run --locked pytest tests/test&#95;ai&#95;service.py -q</code> |
| CLI만 실행 | <code>uv run --locked pytest tests/test&#95;cli.py -q</code> |
| Git 서비스만 실행 | <code>uv run --locked pytest tests/test&#95;git&#95;service.py -q</code> |
| 함수 하나의 모든 조합 실행 | <code>uv run --locked pytest tests/test&#95;ai&#95;service.py::test&#95;title&#95;length&#95;boundaries -v</code> |

이 문서 작성 시에는 설치된 전용 가상환경의 Python에서 pytest를 실행했으며, 캐시 생성을 끄고 임시 저장소 경로를 따로 지정했습니다. 위 명령은 사용자가 같은 테스트를 다시 확인하기 위한 실행 예입니다.

테스트가 추가되거나 매개변수·assertion이 바뀌면 함수 수, 케이스 수, 조건·기대 결과, 실행 결과를 함께 갱신해야 합니다. 전체 동작을 수동 검증하는 방법은 [검증 시나리오](검증_시나리오.md)를 참고합니다.
