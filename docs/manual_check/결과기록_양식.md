## 판정 원칙

- PASS는 실행·확인한 항목에만 표시합니다.
- 모의 HTTP 응답으로 확인한 것은 실제 API 연동 성공으로 기록하지 않습니다.
- 실제 생성 문구가 매번 동일해야 한다고 요구하지 않습니다. 동일 설정 재현은 요청 조건이 같은지와 실제 결과가 어땠는지를 구분합니다.
- 과제 필수 요구사항과 권장사항, 선택 과제를 분리합니다.
- NOT_RUN은 미실행, BLOCKED는 외부 조건으로 수행 불가, N/A는 현재 구현에 없는 선택 기능입니다.
- 생성된 초안의 사실관계를 읽고, 적용 전 Git 상태를 보존합니다.
